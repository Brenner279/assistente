# RoboLab — Laboratório de Robótica e Automação

Primeira entrega do projeto educativo RoboLab, integrado ao repositório Assistente Educacional.

## Protótipo interativo (offline)
Abra `index.html` em um navegador moderno. Não há dependências externas, bibliotecas remotas ou necessidade de internet.

### Recursos disponíveis
- Controle manual por botões e pelas setas do teclado.
- Robô em uma grade de navegação.
- Montagem de sequência de comandos: avançar, recuar e girar.
- Execução automática da sequência.
- Contador de movimentos, reinício e limpeza do programa.
- Alvo para concluir a missão.

## Scratch
A versão Scratch editável será mantida como projeto principal da evolução. O protótipo HTML serve como bancada de testes funcional enquanto os scripts e os atores Scratch são preparados. O arquivo HTML não substitui o projeto `.sb3`.

## Próximas etapas
1. Validar controles e execução de sequências.
2. Implementar o mesmo comportamento em atores e blocos Scratch.
3. Adicionar sensores simulados (distância e luminosidade).
4. Criar desafios e módulos de automação.

## Uso na feira
O protótipo pode ser copiado para o computador e executado localmente, sem conexão com a internet.
